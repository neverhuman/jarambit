# designs/

Hand-built B-rep design packages from the v2 SWITCHBACK study. None of them is a G3 design: the current design is
generated by evolution, and its CAD is in [`../cad/`](../cad/) and [`../docs/g3/v3.0.0/cad/`](../docs/g3/v3.0.0/cad/).

| package | status |
|---|---|
| [`switchback/C10a/`](switchback/C10a/README.md) | last v2 release candidate (rc4); never machined or tested |
| [`switchback/C9.3/`](switchback/C9.3/README.md) | rc3, superseded by C10a |
| [`switchback/C9.2/`](switchback/C9.2/README.md) | rc2, superseded by C9.3 |

Each package lists its files in `SHA256SUMS`. The CAD files are pinned by the CAD battery and by figure and media
manifests, so they stay at these paths. C9.3's FEM plates for waves 70–75 are the same files as C9.2's and are kept
there only.
