\section{Prospective Representation Research}
\label{sec:agents}
FunSearch provides context for separating language-model program proposals from execution-based evaluation in mathematical and algorithmic settings \cite{funsearch}. It does not establish an agent result in Jarambit. Searching values in the present schema and proposing a different schema or decoder are distinct activities; the retained runs demonstrate the former.

A future controlled study on benign reference CAD tasks could compare human-authored and agent-assisted representation proposals under fixed evaluator versions and review criteria. A proposal would identify types, units, dependencies, serialization and migration rules, and expected tests; retained rejected proposals would permit measurement of invalidity, reconstruction success, and reviewer effort. Those outcomes remain unmeasured here. Human responsibility for the problem definition and interpretation remains essential, while independently controlled evaluators constrain which proposed effects are actually observed.
