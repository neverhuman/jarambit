\section{Agents and the Next Level of Genome Design}
\subsection{From Parameter Search to Typed Representation Proposals}
Searching a fixed vector and changing the representation are different activities: the first explores values under a stable decoder, whereas the second changes which objects can be expressed and how coordinates relate to observations. Agents could assist representation research by proposing typed schemas, explaining dependencies, locating unsupported assumptions, and drafting testable software changes. This is a prospective capability, not an outcome established by the retained runs.

A reviewable representation proposal should state its purpose, schema version, typed fields, units, decoder dependencies, serialization rules, migration behavior, and test oracle, separating intended effects from observed decoder and solver outputs. Only decoder outputs establish what the code produced, and only numerical or physical observations establish model or manufactured behavior.

\subsection{Independent Evaluation and Failure Modes}
The evaluator must remain independently controlled relative to the proposer. An agent that changes a representation must not silently alter acceptance criteria, nor may a reporting adapter redefine missing data as favorable. Separate source authorship, separate runtime execution, and separate model families test different dimensions of independence and should be named explicitly.

Tractable failure modes include unit mismatches, inactive parameters, decoder ambiguities, invalid geometry, incompatible migrations, and evaluator exploitation---producing cases that score well under a proxy while violating the assumptions that made the proxy meaningful. These risks should be measured through invalid-proposal rates, review outcomes, reproducibility, and oracle agreement rather than prose fluency.

\subsection{Prospective Benign Research and Human Responsibility}
A future controlled study on benign reference CAD tasks could compare human-authored and agent-assisted schema proposals under fixed review criteria and evaluator versions, retaining rejected proposals and measuring semantic clarity, decoder reliability, independent reconstruction, and reviewer effort. Expanding the hypotheses considered does not remove human responsibility for problem definition, model selection, evidence interpretation, and deployment: a human author must approve the manuscript's claims, while numerical tools and physical measurements constrain what can be trusted.
