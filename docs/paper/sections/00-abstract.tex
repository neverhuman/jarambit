\begin{abstract}We report a continuous island evolution run with 103 islands, 54,814 Stage 1 candidates and 1,413 Stage 2 assessments. The highest-scoring design, ec2i089\_r01\_p10\_c68, scored 80.851214 and weighed 83.409 g (3D estimate 83.3333 g). It passed only 13 of 26 legacy hard gates. It is not certified. The top five scores occupy a 0.01-point band, a narrow plateau.\end{abstract}
