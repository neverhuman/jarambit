\subsection{Recovery Status}
Fresh-process resumption of the native search is unproven in this accession. Serializing a checkpoint or continuing in its original process does not establish disk-only reconstruction of the complete running state in a new process. Separately scoped neutral integer-stream recovery work concerns only its own fixture state, accepted journal prefix and storage protocol; it does not establish resumption of a production campaign. Any recovery claim requires an actual fresh-process receipt binding the fixture source/binary, full restored state, journal sequence and uninterrupted comparison. Such a receipt is distinct from report reconstruction and from a new scientific evaluation.

\subsection{Immutable Evidence Entry Points}
The \href{https://github.com/neverhuman/jarambit/blob/102cdbef52b3710ce360ac34475c96ede0e33970/docs/paper/CROSSWALK_SUPPLEMENT.md}{retained technical crosswalk} provides the public-ID mappings and access to the historical matrix, export identities and original field inventory. The \href{https://github.com/neverhuman/jarambit/blob/102cdbef52b3710ce360ac34475c96ede0e33970/artifacts/versioned-evolution-archives-gen800-population-v1/index.gen800_population.sha256.json}{completed-population archive index} identifies ten run manifests and 200 compressed segments. These links identify the prior retained evidence accession; they are not a claim that the present revised manuscript was authored at that revision. The final publication receipt supplies the matching manuscript/build accession and standalone supplement access. A TeX include fragment is source, not a compiled supplement download.

Candidate, producer, reporting-source and publication identities remain distinct. For example, a certificate hash binds content identity under its scheme; it does not prove a CAD artifact exists. The archived producer revision is preserved with its original inputs rather than replaced by the present manuscript revision. The matching publication receipt must bind the actual manuscript head/tree, build environment, main and supplement PDF hashes, generated outputs and receiving-main/release accession. Receiving-tree equality establishes the delivered source bytes; it does not reconstruct an unrecorded historical producer execution. Hash equality establishes byte identity, not correctness of the original computation.

\subsection{Reporting Commands and Writes}
The reporting environment requires Rust/Cargo with the locked dependencies and complete admitted archives; document production additionally requires LuaLaTeX/IEEEtran, the declared fonts, librsvg and PDF inspection tools. From the repository root, the following commands request a full compressed-population audit and retain the existing document-build/check entry points. Commands are shown at full width so flags remain copyable; actual exits/toolchain/output hashes belong to the final validation receipt.

The artifact audit decodes admitted historical frames, checks proposal/screen joins, verifies compressed-segment and reporting bindings, and checks generated-output consistency. Its flag-controlled compressed-segment decoder defaults to one segment per run; \code{--full-zstd} removes that limit. For the admitted completed-population accession, full scope is 200 segments containing \num{\CohortThreeTotalEvaluations} rows. The final exact-head receipt must establish the requested mode, actual segment/row counts and successful exit; documenting the command alone does not establish its execution. The document check renders figures and compiles the paper under \nolinkurl{target/ieee/paper/}, and the existing build also updates \nolinkurl{docs/paper/main.pdf}. Evidence inputs remain read only; the entire operation is not filesystem read only. The supplement target, complete input manifest, all-page visual inspection and clickable-link checks are part of the matching publication package rather than implied by the existence of source files.
