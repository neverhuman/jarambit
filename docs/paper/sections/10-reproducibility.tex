\section{Reproducibility, Supplement Crosswalk, and Publication Provenance}
\label{sec:reproducibility}

\subsection{Four Distinct Reproduction Claims}
This manuscript reconstructs documentation projections and population censuses from retained repository records; it does not rerun finite-element solvers or validate physical hardware. The standalone Rust verification package reads the frozen battery and science catalogs, three-cohort population ledgers, identity registries, and compressed generation-800 archives in read-only check mode without invoking CAD or FEM kernels. Chart reconstruction, solver replay, software-control execution, and physical replication establish different scientific claims and are kept strictly separate.

\subsection{Deterministic Verification Gate}
The repository verification gate executes two read-only checks from the repository root:
\begin{verbatim}
cargo run --release --locked --manifest-path \
  crates/paper-artifacts/Cargo.toml \
  --example publication_v2_audit
make -C docs/paper check
\end{verbatim}
The first command verifies all metadata contracts, decodes the binary event frames of \text{Run~1}, verifies the 57-file one-based join and zero-based negative control of Cohort~2, decompresses and checks the $200$ compressed segments ($3{,}811{,}896{,}749$ raw bytes) and scatter-cache bindings of Cohort~3, and confirms byte-for-byte freshness of all generated outputs without writing files. The second command renders the SVG figures, compiles \code{main.pdf}, verifies zero undefined references or overfull boxes, and checks the 15--20 page budget.
