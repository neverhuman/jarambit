Lateral and torsion fields use DKT bending stresses recovered as a maximum over three extrapolated corners. Pry and ring fields use T6 centroid von Mises stress. In particular, \nolinkurl{/mesh/pry} has $25{,}209$ stored unit-load values and peak $2.9181\,\mathrm{MPa/N}$. The original field contract's display-field list omits this array. Its interpretation here is additive, checked against the bound producer sources; the original contract bytes remain preserved.

The ring producer zeroes cells whose centroid satisfies \code{cen[e].0 >= sx0 - 3.0}, a half-plane criterion rather than a seat-only exclusion. The retained ring field has $10{,}334$ active cells and $14{,}875$ source-masked cells. These mask zeros are not measured zero stresses.
