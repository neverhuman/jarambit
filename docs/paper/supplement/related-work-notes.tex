The main comparison concerns representation, search, evidence retention, and validation scope. DeepCAD and Text2CAD concern CAD sequences and learned generation \cite{deepcad,text2cad}. The present study does not implement or test a PROV interchange profile. FAIR's discovery and reuse goals and software-citation specificity help separate an accessible research object from a checksum alone \cite{fair,softwarecitation}. A source snapshot is cited as a snapshot; its identity is not substituted for an unrecorded execution environment or for this manuscript's eventual release identity.

Software methods references support library roles, not a numerical model's validation \cite{skfem,dolfinx}. The cited DOLFINx v1 preprint from 2023 remains a valid publication object; it differs from the retained DOLFINx 0.9.0 environment. The retained SciPy 1.18.1 capture and its cache/execution-binding limitation are described in Section~\ref{sec:numerical-methods-details}. Roache's grid-refinement reference is retained \cite{roache}; the bound reporting procedure and its actual refusal rules, rather than the citation alone, establish which estimates were admitted.

Crameri \emph{et al.} motivate attention to perceptual color gradients and accessibility \cite{crameri}. This citation does not validate Jarambit's percentile composite, lighting, saliency choices, or final figure accessibility. Those require their own definitions and final visual inspection. The NIST artifact supports distinguishing digital geometry from measured process behavior \cite{nistartifact}. NASA's standard supplies credibility context; compliance is not asserted \cite{nasa}.
